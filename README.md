## Concept

A first-person survival game aboard a failing spaceship. Systems keep breaking, alarms blare, and you race between stations to complete fix-it minigames before a malfunction kills you (think Among Us tasks and sabotages, solo).

## How to Run

1. Install Godot 4.7.
2. Open `red-alert/project.godot`.
3. Press F5.

### Controls

- **WASD**: Move
- **Space**: Jump
- **Mouse**: Look
- **E**: Interact
- **Esc**: Release mouse
